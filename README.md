California Wildfire Analysis Dashboard

A spatial-temporal data visualization project built using Power BI, Python, Pandas, and GIS mapping techniques to analyse wildfire patterns in California from 2014 to February 2025.
The dashboard highlights key wildfire trends, identifies high-risk counties, and reveals human-driven causes using a structured, intuitive visual storytelling approach.

🔥 Project Summary

This project transforms raw Kaggle wildfire data into an interactive dashboard designed for policymakers, emergency planners, and environmental analysts.
The dashboard presents the wildfire crisis through a clear hierarchical flow — What’s happening → When → Where → Why — enabling fast, evidence-based decision-making.

📊 Key Features

KPI cards summarising acres burned, total incidents, deaths, and economic losses

Time-series visual showing wildfire intensity trends over 11 years

Geographic heatmap of counties with highest fire activity

Bar charts for incident distribution across regions

Donut chart highlighting ignition causes (human vs natural)

Interactive filters for year and county selection

Clean, minimal visual design using purposeful fire-themed colours

🛠 Tech Stack

Power BI – dashboard, mapping, KPIs

Python (Pandas) – preprocessing & cleaning

CSV (Kaggle dataset) – wildfire incident records

Jupyter Notebook – data preparation workflow

GIS Mapping – county-level spatial insight
